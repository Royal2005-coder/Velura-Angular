# Specification: Velura Admin ERP SaaS UI/UX Excellence, Anti-Overflow & Topic Icon System (`KAN-118`)

## 1. Problem Statement
A full-codebase audit across `apps/admin-erp-ng` (Shell, Auth, 16 Shared UI Primitives, and all 11 ERP Modules) surfaced systemic UI/UX gaps preventing a cohesive, enterprise SaaS operator experience:
1. **Duplicate & Misleading Iconography**: 6 of 11 sidebar items share duplicate icons (`tag` ×2, `star` ×2, `log` ×2 plus Sign-out), `alert` is overused 26 times (including neutral empty states and discount KPIs), and tables lack semantic topic cues.
2. **Layout & Table Overflow Traps**: `<app-erp-data-table>` triggers `table-layout: fixed` whenever even a single column sets `width`/`truncate`, crushing remaining columns; `Products` hides stock quantities when low-stock badges render; 5–6 column KPI grids overflow at `1280px–1440px` with sidebar open; 40 CSS variable usages (`--erp-text-muted`, `--erp-input-border`, `--erp-sidebar-accent`, etc.) are undefined in `:root`; `auth-frame.ts` renders `#BE185D` text over a `#BE185D` gradient.
3. **Unwired Operator Productivity Affordances**: `orderRowActions`, `priceRowActions`, `accountRowActions`, `pageSizes`, `hasFilters` empty-state reset, and `Pricing`/`Accounts`/`Orders` drawer `J`/`K` navigation exist in ViewModels or partially in templates without complete bindings; `⌘K` Command Palette lacks arrow/Enter keyboard navigation and deep sub-queue targets; key identifiers (order codes, SKUs, voucher codes, phones/emails) lack 1-click copy.

## 2. Functional Requirements
- **FR-01 (54-Glyph Cohesive Topic Icon System)**: Expand `public/admin-assets/icons/admin-icons.svg` with uniform `24x24` `1.75px`-stroke line icons so all 11 sidebar modules, sign-out, empty states (`inbox`), toast tones, KPI tiles, and table headers/cells carry distinct, domain-accurate icons.
- **FR-02 (Zero-Overflow Responsive Grids & Complete Token Contract)**: Resolve all 8 missing `--erp-*` CSS custom property aliases in `styles.scss`, standardize `.erp-kpi-grid` (`auto-fit, minmax(190px, 1fr)`) with `min-width: 0` and clamped tabular numerals, and fix `auth-frame.ts` contrast + `100dvh` viewport sizing + password show/hide toggle.
- **FR-03 (SaaS Data Table Engine)**: Upgrade `AdminErpDataTable` to support content-aware column sizing (`minWidth`, `width`, `truncate` max-width without forcing equal-width `table-fixed` crushing), universal hover `title` on text cells, header topic `icon`, 2-line `subtext`, `cellIcon`, `secondaryBadge` alongside primary value, inline 1-click `copyValue` with toast confirmation, and sticky right `.col-actions`.
- **FR-04 (Power-Operator Shell & `⌘K` Command Palette)**: Add collapsed-sidebar rail tooltips, keyboard navigation (`ArrowUp`/`ArrowDown`/`Enter`) in `⌘K`, 16 deep sub-queue shortcuts (e.g. *Đơn lỗi thanh toán*, *Biến thể sắp hết*, *Quản lý Banner*, *Bộ sưu tập*, *Yêu cầu nâng quyền*), and a keyboard shortcut footer legend.
- **FR-05 (11-Module Harmonization & Interactive UX)**: Wire all row quick-actions, clickable KPI queue filters, `Xoá bộ lọc` empty-state recovery, rows-per-page selectors, `J`/`K` drawer record navigation, modal `[dirty]`/`[busy]` guards, and cohesive Vietnamese panel headers across Dashboard, Orders, Returns, Products, Pricing, Promotions, Reviews, Content, Accounts, Members, and Logs while keeping every component SCSS `< 32kB` and preserving all API/RBAC contracts.
